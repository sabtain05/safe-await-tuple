# Security Policy

## Supported Versions

We take the security of `safe-await-tuple` very seriously. The following versions are currently supported with security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `safe-await-tuple`, please report it responsibly. 

* **Do not** disclose security vulnerabilities publicly until they have been addressed and a patch has been released.
* Please send your vulnerability reports directly to the maintainer via email or open a private advisory on the GitHub repository.

You can expect an initial response acknowledging receipt of your report within 48 hours, followed by regular updates as we investigate and deploy a fix. Thank you for helping keep the ecosystem safe!
